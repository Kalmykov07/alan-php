# Deaf Grandma

## Описание проекта

Веб-приложение "Глухая бабушка" представляет собой интерактивный чат-бот, имитирующий диалог с пожилой женщиной с нарушениями слуха. Приложение реализовано на PHP с использованием сессий для сохранения истории диалога.

## Функциональность

- **Интерактивный диалог**: пользователь вводит сообщения, бабушка отвечает согласно определенным правилам
- **Обработка команд**: система распознает ключевые слова и знаки препинания
- **Сохранение состояния**: история диалога сохраняется в сессии
- **Завершение диалога**: возможность завершить беседу тремя последовательными "Пока!"

## Правила взаимодействия

### Режимы ответов

| Условие | Реакция бабушки |
|---------|-----------------|
| Сообщение без восклицательного знака | "АСЬ?! ГОВОРИ ГРОМЧЕ, ВНУЧЕК!" |
| Сообщение с восклицательным знаком | "НЕТ, НИ РАЗУ С [год] ГОДА!" |
| Первое и второе "Пока!" | "НЕТ, НИ РАЗУ С [год] ГОДА!" |
| Третье "Пока!" | "ДО СВИДАНИЯ, МИЛЫЙ! ЗАХОДИ ЕЩЁ!" |

### Генерация годов

При ответе на сообщения с восклицательным знаком генерируется случайный год в диапазоне 1930-1950.

## Техническая реализация

### Серверная часть (PHP)

- **Управление сессиями**: хранение истории диалога и состояния приложения
- **Обработка ввода**: распознавание команд и формирование ответов
- **Кириллические преобразования**: функция `ruStrtoupper()` для корректной работы с русскими буквами
- **Логирование**: отладка через `error_log()`

### Клиентская часть

- **Адаптивный интерфейс**: поддержка мобильных устройств
- **Автоскроллинг**: автоматическая прокрутка к новым сообщениям
- **Управление состоянием**: отключение полей ввода после завершения диалога
